¿Qué es una API Externa?

Una API Externa (Application Programming Interface) es un conjunto de protocolos y definiciones que permite a una aplicación consumir datos, funcionalidades y servicios provistos por un tercero a través de la red (generalmente HTTP/HTTPS).

En arquitecturas de backend desacopladas, consumir una API externa permite delegar responsabilidades complejas (información climática global, procesamiento de pagos, geocodificación, mensajería, inteligencia artificial) sin tener que almacenar ni procesar dichos datos localmente.

RapidAPI (https://rapidapi.com/)

RapidAPI es el marketplace de APIs más grande del mundo, con decenas de miles de APIs catalogadas. Sus características clave incluyen:

  • Clave API Única (Single API Key): Permite consumir cientos de proveedores distintos utilizando una única cuenta y cabecera de autenticación (X-RapidAPI-Key).
  • Dashboard de Métricas & Facturación Centralizada: Monitoreo de latencia, cuotas, errores 4xx/5xx y costos unificados.
  • Consola Interactiva: Pruebas en vivo en el navegador antes de escribir código.
OpenWeatherMap (https://openweathermap.org/api)

Es uno de los proveedores meteorológicos más populares a nivel global.

  • Mecanismo de Autenticación: Requiere registrarse y enviar un token appid en los query params de cada petición HTTP.
  • Endpoints Principales: Current Weather Data (clima actual), 5 Day / 3 Hour Forecast (pronóstico trihorario), Geocoding API y One Call API 3.0.
  • Limitaciones Free Tier: Plan gratuito limitado a 60 llamadas por minuto o 1,000 llamadas por día en One Call 3.0, requiriendo tarjeta de crédito para llamadas adicionales.
Open-Meteo (Nuestra API Implementada)

Servicio meteorológico de código abierto alimentado por centros de investigación globales (DWD, NOAA, ECMWF).

  • Sin API Key Obligatoria: Permite consumo inmediato y sin fricción de credenciales, ideal para docencia y entornos educativos.
  • Alta Precisión: Predicciones horarias y diarias con modelos numéricos de hasta 1 km de resolución.
  • Cumplimiento de estándares: Retorna códigos internacionales WMO (World Meteorological Organization).
Magic Loops (https://magicloops.dev/es)

Magic Loops es una plataforma no-code / low-code impulsada por Inteligencia Artificial que permite crear flujos de trabajo automatizados y exponerlos como APIs REST personalizadas sin escribir infraestructura de servidores.

Triggers Programados

Ejecución recurrente estilo Cron Jobs para recolectar datos o ejecutar reportes periódicos.

Nodos de IA (LLMs)

Transformación semántica de datos, resumen de textos o toma de decisiones lógica guiada por prompts.

Webhooks & Salidas

Envío automático de correos, llamadas a Discord, Slack o webhooks HTTP a sistemas externos como nuestro Backend.

Acceso a la API de WhatsApp (Meta Cloud API)
  1. Cuenta en Meta for Developers: Crear una cuenta en developers.facebook.com y dar de alta una App de tipo "Business".
  2. WhatsApp Business Account (WABA): Asociar o verificar la empresa en Meta Business Manager.
  3. Número de Teléfono: Registrar un número dedicado que no esté asociado a una app convencional de WhatsApp.
  4. Tokens de Acceso: Generar tokens de usuario del sistema (System User Access Token) con permiso whatsapp_business_messaging.
  5. Plantillas de Mensaje (Templates): Para iniciar conversaciones hacia el usuario fuera de la ventana de 24 horas, Meta exige enviar plantillas pre-aprobadas (categorías: Utility, Authentication, Marketing).
Utilidad Futura para el Equipo de Desarrollo

En un proyecto real (como el sistema de Gestión de Biblioteca o un sistema de Turnos Médicos de ejercicios previos), la API de WhatsApp aporta un valor diferencial:

  • Recordatorios de Vencimiento de Libros: Notificación automática al usuario 24h antes del vencimiento del préstamo para evitar penalidades.
  • Envío de Comprobantes PDF / QR: Envío inmediato del comprobante digital de préstamo o turno al celular del usuario.
  • Autenticación en Dos Pasos (2FA / OTP): Envío seguro del código de validación al iniciar sesión en el portal web.
  • Chatbot de Autoconsulta: Consultar disponibilidad de libros en el catálogo respondiendo directamente por chat con opciones interactivas.
Uso de RestTemplate en Spring Boot

RestTemplate es el cliente HTTP sincrónico central de Spring Framework. Ofrece métodos de alto nivel para consumir servicios REST:

Método RestTemplate Método HTTP Descripción en nuestro Proyecto
getForObject(uri, Class<T>) GET Obtiene directamente el cuerpo de la respuesta deserializado a String o DTO (ej. datos de clima de Open-Meteo).
exchange(url, HttpMethod, HttpEntity, Class<T>) POST / CUALQUIERA Permite personalizar headers (como Authorization: Bearer) y enviar payloads complejos a WhatsApp Cloud API.
UriComponentsBuilder UTIL Construcción segura de URLs y codificación de parámetros query (latitud, longitud, ciudad).
